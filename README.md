# 麻雀 何切るクイズ

Mortal（[mjai.ekyu.moe](https://mjai.ekyu.moe/)）の牌譜検討URLを貼り付けると、
AIの推奨打牌と食い違った局面（error）だけを抜き出して「何切る」クイズにするスマホ向けWebアプリ。

- 検討URLの JSON を直接読むので **API利用料は0円**
- 出題時はAIの推奨・実戦打牌をマスク表示、「答えを見る」でマスク解除
- 自己採点で「正解 / 不正解 / 要復習」リストに蓄積（端末内のIndexedDBに保存）
- 出題は「不正解だけ」「要復習だけ」「未出題だけ」「正解済みだけ」「おまかせ」から選択でき、
  一覧は牌譜ごとにグループ化して、そのリストだけを出題できる
- 何切るだけでなく、チー/ポン/カンの鳴き判断ミス、リーチ判断ミスも出題対象
- 各問題の画面から磯部さんに質問できる。質問は牌譜の図つきで「磯部さんへの質問用アプリ」（`isobe.html`）に届き、
  磯部さんの回答は自動でこちらに届く（回答待ち／回答済み）。追加の質問もでき、やり取りの履歴が残る。
  回答は目隠しして出題し、「磯部さんの質問クイズ」モードでも出題される
- 天鳳の牌譜URL（`tenhou.net/0/?log=…`）や天鳳Web版の保存データ（`log0={…}`）も貼り付け可能。
  Mortal（mjai.ekyu.moe）の画面を牌譜URL入力済みで開くので、「送信」して結果URLを貼り戻せば取り込める
  （mjai.ekyu.moe は Cloudflare の人間確認付きのため、送信だけは手動。東風戦はMortal非対応）

任意機能として、牌譜スクリーンショットをClaude APIで読み取って問題化することもできます（自分のAPIキーが必要）。

雀魂（じゃんたま）の牌譜は `tools/majsoul/` で一括処理できます（牌譜URLの一括取得スクリプト＋Mortalに順番にかけるChrome拡張）。
「牌譜URL ⇥ Mortal結果URL」の形で貼ると、牌譜URLを紐づけたまままとめて取り込めます。詳しくは `tools/majsoul/README.md`。

静的ファイルのみ。GitHub Pages で動作します。

## ローカル麻雀（`play.html`）— Mortal代役AI×3と打つオフライン半荘戦

`play.html` は、Mortal の解析結果から学習した **Mortal代役AI** を3人のCPUにして、あなたと4人で半荘戦を打つアプリです。
一度ネットで開けば、以降は **機内モード・オフラインでも** 遊べます（Service Worker `sw.js` がアプリ一式を端末に保存）。
AIの推論も端末内で行い、通信もAPI利用料もありません。

- CPUの持ち時間は1手0.3秒、あなたの持ち時間は無制限
- 「正解がわからない」：その場の判断（打牌・リーチ・ポン/チー/カン・ロン）について、Mortal代役の評価を Mortal の検討画面風に％で表示
- Mortal代役の推奨と違う手を選ぶと、赤字で **FALSE** を表示して止まり、推奨手を％つきで表示。「再開」で続行（推奨どおりなら止まらない）
- 「メモ記入」：その局面を **要チェック** に登録。ホーム画面の「要チェック」であとからまとめて確認
- 「シャンテン数＆待ち表示」（初期は非表示）：シャンテン数と、打牌ごとの受け入れ牌・枚数
- 「今スジが何本通っているか？」：相手ごとに通っている筋（18本中）を表示
- 「スジカウント表」（初期は非表示）：自主学習用のカウンターと、書き込めるスジ対応表（答え合わせつき）
- 「相手の手牌OPEN」：対局中に相手の手牌を表示
- 「縦画面モード」「横画面モード」：ボタンでだけ切り替わる（端末の傾きでは切り替わらない）。iPhone 11 の画面に合わせて配置
- 牌譜一覧：すべての半荘の牌譜を、**全員の手牌を表示して** 最初から最後まで再生。自分の判断ごとに OK / FALSE と候補の％を表示
- 中断しても「続きから」で同じ局面から再開できる
- **復習半荘**：牌譜データ.json・牌譜データv3 の半荘（Mortal の解析済み）から1半荘を選び、東1局から最後の局まで全局を全く同じ手牌・同じ進行で打つモード（実戦で Mortal の推奨率20%以下の手を選んだ回数が多い半荘から順に出題。一覧から選ぶこともできる）。
  あなたの判断は **本物の Mortal の解析結果** と照合し、違えば FALSE（実戦で何を打ったかも表示）。判断のあとも局は実際の牌譜どおりに進む
  牌譜データv3 の天鳳URLは、天鳳の牌譜そのものを取得して同じ手牌・同じ進行を再現する。同じ半荘の Mortal レポートがあれば（配牌で照合）本物の Mortal で判定し、
  Mortal 未解析の半荘は Mortal代役AI で判定する（画面に「Mortal未解析・代役判定」と表示）
- **何切るクイズから復習半荘に追加**：何切るクイズで Mortal の解析（天鳳・雀魂の牌譜URLから送ったものも含む）を取り込むと、
  その半荘が自動で復習半荘モードに追加される（取り込み時のレポートをそのまま変換するので、追加のための通信はない。変換は `local/review-build.js`。`build-review.js` と共通）。
  自動追加より前に取り込んだ牌譜は、「一覧」の「復習半荘モードに追加」ボタン（牌譜ごと）か「これまで取り込んだ牌譜をまとめて復習半荘モードに追加」で追加できる。
  復習半荘のデータ（`review-data.js`）にすでにある牌譜は、通信せずに追加する（ID の一覧 `local/review-ids.js` は `build-review.js` が作る）。
  追加した半荘は復習半荘の出題順に加わり、本物の Mortal で判定する（すでに牌譜データv2 にある半荘は復習半荘に移る）。東風戦は追加されない
- **出題一覧**：半荘ごとに「未プレイ／途中／プレイ中／プレイ済み（回数）」と、プレイ結果（一致率と、同じ場面の実戦の一致率）を表示。
  天鳳から取り込んだ半荘は、対局日時と何切るクイズでの取り込み日時も表示する
- **不正解のみプレイ**：その半荘で、これまでのプレイで最後に FALSE だった判断の場面だけで止まる（ほかは実戦の手で早送り。正解すると対象から外れる）
- **学習用牌譜（v2）から出題**：牌譜データv2 は Mortal代役AIの学習用で、復習半荘には混ぜない。v2 の半荘は、この別モードで同じ方法で出題する
- ルール：半荘戦・喰いタンあり・赤ドラ3枚・ダブロンあり・西入（サドンデス）・飛びあり・オーラス和了止め（天鳳準拠。責任払いは未対応）

何切るクイズ（`index.html`）の「ローカルプレイ結果」タブから、ローカル対局の牌譜を開けます。
FALSE になった判断とメモした局面は何切るクイズの問題として自動で取り込まれ（牌譜ごとに解ける）、各問題から磯部さんに質問できます。

Mortal代役AIの学習方法・再学習の手順は `tools/local-ai/README.md` を参照してください。

## データの保存

問題と学習状況（正解／不正解／要復習）は端末内の **IndexedDB と localStorage の両方**に保存し、
片方が消えても起動時にもう片方から自動復元します。取り込み元のURLも控えているので、
両方消えても「取り込み」タブの再取り込みでワンタップで作り直せます（学習状況も復元）。

## 磯部さんとのやり取り（Firestore）

- やり取りは Firebase プロジェクト `mahjong-isobe-qa`（Spark・無料）の Firestore に保存。SDK は使わず REST で読み書き（`qa.js`）
- `rooms/{合言葉}/threads/{tid}`（牌譜の図・局面情報）と `.../msgs/{mid}`（1通ずつ）
- セキュリティルールで「合言葉（24〜64文字）を知っている人だけ読み書き可・削除不可・部屋一覧の取得不可」にしている
- 合言葉はリポジトリに置かない。端末ごとに自動生成し、設定タブの「磯部さん用URL」（`isobe.html#合言葉`）で磯部さんに渡す。
  別端末へは「引き継ぎ用URL」（`#room=合言葉`）で引き継ぐ
