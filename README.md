# 麻雀 何切るクイズ

Mortal（[mjai.ekyu.moe](https://mjai.ekyu.moe/)）の牌譜検討URLを貼り付けると、
AIの推奨打牌と食い違った局面（error）だけを抜き出して「何切る」クイズにするスマホ向けWebアプリ。

- 検討URLの JSON を直接読むので **API利用料は0円**
- 出題時はAIの推奨・実戦打牌をマスク表示、「答えを見る」でマスク解除
- 自己採点で「正解 / 不正解 / 要復習」リストに蓄積（端末内のIndexedDBに保存）
- 出題は「不正解だけ」「要復習だけ」「未出題だけ」「正解済みだけ」「おまかせ」から選択でき、
  一覧は牌譜ごとにグループ化して、そのリストだけを出題できる
- 何切るだけでなく、チー/ポン/カンの鳴き判断ミス、リーチ判断ミスも出題対象

任意機能として、牌譜スクリーンショットをClaude APIで読み取って問題化することもできます（自分のAPIキーが必要）。

静的ファイルのみ。GitHub Pages で動作します。

## データの保存

問題と学習状況（正解／不正解／要復習）は端末内の **IndexedDB と localStorage の両方**に保存し、
片方が消えても起動時にもう片方から自動復元します。取り込み元のURLも控えているので、
両方消えても「取り込み」タブの再取り込みでワンタップで作り直せます（学習状況も復元）。
